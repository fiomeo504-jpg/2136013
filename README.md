# 🎯 Random Task Generator

**Автор:** Каргина Анна Владимировна

## 📌 Описание проекта

**Random Task Generator** — это милое и полезное приложение для генерации случайных задач на день. Программа поможет разнообразить учебные, спортивные и рабочие дела, а также сохранит историю всех выполненных заданий.

### Что умеет программа:
- 🎲 **Генерация случайной задачи** из готового списка
- 📝 **Добавление своей задачи** с выбором типа
- 🔍 **Фильтрация истории** по типу задач
- 💾 **Сохранение истории** в JSON файл
- 📂 **Автоматическая загрузка** при запуске
- 🗑 **Очистка истории** (с подтверждением)
- 📊 **Статистика** количества задач по типам
